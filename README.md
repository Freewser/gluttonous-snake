# 贪吃蛇大冒险 · Gluttonous Snake

纯前端贪吃蛇小游戏，零依赖，浏览器打开即玩。包含「闯关模式」与「经典模式」双玩法。

## 运行

直接用浏览器打开 `index.html` 即可（双击文件或拖入浏览器）。

## 操作

| 按键 | 功能 |
| --- | --- |
| ↑ ↓ ← → / WASD | 控制方向 |
| 空格 | 开始 / 暂停 / 继续 |
| R | 重新开始 |
| 📋 按钮 | 查看历史对局记录（最近 10 局，可清空） |
| 手机滑动 | 控制方向 |

> 快速连按时，反向输入会取消尚未执行的转向，最后按下的方向生效。

## 闯关模式

- 共 **12 关**，每关拥有独立主题（草原、森林、沙漠、冰川、熔岩、深海、霓虹、古堡、樱花、矿山、星空、终极试炼）、专属配色、主题食物与障碍风格。
- **障碍每把随机刷新**：每次挑战按关卡密度与样式（散布 / 方块 / 线条 / 混合，部分关卡左右对称）随机生成障碍，并保证起点周围空旷、全图连通、食物必定可达。
- 每关需要吃满目标数量的食物即可通关，通关解锁下一关。
- **命数规则**：每次挑战默认 3 条命，撞墙或咬到自己消耗 1 条命后从本关开头重新挑战；3 条命用完则挑战失败，需从头再来。
- **碰撞宽限**：蛇即将撞墙/撞障碍/咬到自己时会急停 0.4 秒（红框闪烁、蛇头变红），期间转向安全方向即可救回，超时才扣命。
- **星级评价**：按通关用时评星 ——
  - ★（达标）：3 条命
  - ★★（更快）：下次挑战 4 条命
  - ★★★（最快）：下次挑战 5 条命
- 历史星级会一直保留，再次挑战已通关关卡时按最高星级享受对应命数。

## 经典模式

- 经典无尽玩法：吃到食物 +10 分，蛇身变长，每吃 5 个食物速度升一档（最高 10 级）。
- 撞到墙壁或咬到自己游戏结束，最高分自动保存。

## 历史记录

- 每局结束自动保存历史记录（模式、得分、食物数、用时、时间），最多保留 10 局，可随时清空。

## 文件结构

- `index.html` 页面结构
- `style.css` 界面样式
- `levels.js` 12 个关卡的主题、数值与随机障碍生成配置
- `game.js` 游戏逻辑（Canvas 渲染、双模式引擎、存档）
